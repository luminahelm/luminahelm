# Hi, I'm Lumina 👋

I build businesses, not just products. Every repo here is run as a P&L — what's the cost, what's the return, and what's the smallest experiment that tells me whether to keep going or kill it.

## How I think

- **ROI first, code second.** The best line of code is the one that doesn't get written because the problem doesn't exist.
- **Cheap experiments over big bets.** A $500 prototype that kills a $50K idea in a week is a win.
- **Decisions live next to the numbers.** Every bet gets a thesis, a kill metric, and a deadline. No "we'll figure it out later."
- **Compounding > novelty.** I'd rather grind one channel into a reliable engine than chase five new ones.

## What I'm good at

- Translating fuzzy markets into a unit-economics model I can defend
- Picking the 20% of features that drive 80% of willingness to pay
- Building the leanest possible stack to validate, then scaling only what survives
- Reading the room — knowing when a market is ready and when it isn't
